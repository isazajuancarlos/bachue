# bachue

**An identity provider (OpenID Connect) for your own applications** — sign-in,
tokens and session, done once and done right.

**English** · [Español](#español)

---

## What it is

`bachue` is an OpenID Connect identity provider: the piece that handles who a user
is, issues and verifies tokens, and manages sessions, so each application doesn't
reinvent authentication — and doesn't get it subtly wrong. It is the identity
cornerstone that other Xiliux products build on.

## Who it's for

Teams running more than one application that want a single, correct place for
sign-in and authorization, instead of a copy of the auth code in every service.

## Español

### Qué es

`bachue` es un proveedor de identidad OpenID Connect: la pieza que resuelve quién
es un usuario, emite y verifica tokens, y gestiona la sesión, para que cada
aplicación no reinvente la autenticación —ni la haga sutilmente mal—. Es la piedra
angular de identidad sobre la que se apoyan otros productos de Xiliux.

### Para quién

Equipos con más de una aplicación que quieren un único lugar correcto para el
inicio de sesión y la autorización, en vez de una copia del código de auth en cada
servicio.
